# Portfolio

A personal portfolio web application built with React (Frontend) and Django REST Framework (Backend).

## Project Structure

- **`frontend/`**: React + Vite single page application with modern UI components and styles.
- **`Backend/`**: Django REST API backend service.

## Getting Started

### Backend
1. Navigate to `Backend/`
2. Create and activate a virtual environment
3. Install dependencies: `pip install -r requirements.txt`
4. Run migrations: `python manage.py migrate`
5. Start development server: `python manage.py runserver`

### Frontend
1. Navigate to `frontend/`
2. Install dependencies: `npm install`
3. Start dev server: `npm run dev`
